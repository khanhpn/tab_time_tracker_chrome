# Tab Time Tracker

A Chrome Extension Manifest V3 popup that shows how long the current active tab has been in use.

## Features

- Shows elapsed time for the current active tab
- Resets automatically when switching tabs
- Shows current tab title and domain
- Optional pause when Chrome loses focus
- Optional badge text on the extension icon
- Lightweight popup-only UI
- No webpage overlay
- No external network requests

## Local install

Open `chrome://extensions`, enable Developer mode, click Load unpacked, then select this folder.

## Package for Chrome Web Store

Zip the folder contents so `manifest.json` is at the root of the zip.
